# 家庭百万富翁 · 使用说明

## 第一次使用（3 步）
1. 双击 `start.bat`。黑色窗口里会打印出局域网地址，例如 `http://192.168.1.23:3000/`。**这个窗口要一直开着**，关掉游戏就停了。
2. **电视**（Edge 浏览器）输入 `http://你的IP:3000/`，出现标题画面后点一下（或按遥控器确定键），这样才有音效。
3. **主持人的手机**（连同一个 Wi-Fi）打开 `http://你的IP:3000/host`，这就是主持人遥控器。电脑浏览器也能开，手机上建议加到主屏幕/收藏夹。

连不上时按顺序检查：
- 手机和电脑、电视盒子是否在同一个 Wi-Fi（不要用"访客网络"）；
- 右键 `放行防火墙.bat` →「以管理员身份运行」一次；或者第一次启动时 Windows 弹出防火墙提示，勾选"专用网络"并允许；
- 电脑别休眠：设置 → 系统 → 电源 → 屏幕和睡眠 →「接通电源后，使计算机进入睡眠状态」选"从不"；
- 路由器里给这台电脑绑定固定 IP，以后电视上的地址就不会变。电视上可以把地址存成书签。
- 端口被占用时，改 `config.json` 里的 `port`。

## 一局怎么玩
1. 主持人面板「遥控」页点选手名字 → 电视出第 1 题。
2. 选手口头回答，你点对应选项（电视上会高亮），再点「锁定答案」。电视进入悬念，约 4 秒后揭晓，并显示解析，这时可以给孩子讲两句。
3. 答对：点「下一题」，或者「见好就收」带走当前奖金。答错：点「结算本局」。
4. 求助：「50:50」去掉两个错误选项，「换题」换成同分类、同学段的另一题，各一次。用求助前要先「取消选择」。
5. 奖金 1→2→3→4→5→6→8→10→12→14→16→20；第 5 题（5 元）、第 9 题（12 元）是保险线，答错退回最近的保险线。
6. 一局结束后可以「再来一局」或回大厅换人，每人历史最高奖金、局数、通关次数会自动记录，大厅里还有"爸爸累计发出"的总账。

抽题：每道题有学段标签（小学/初中/高中/大学），每位选手也有自己的学段（「记分牌」→ 改）。每局 12 题分三档、每档 4 题（文史/理科/通识/二次元各一题），三档依次取 **学段-1、学段、学段+1** 的题：
  - 选「初中」（默认小女儿）：前 4 题小学、中间 4 题初中、最后 4 题高中；
  - 选「大学」（默认太太）：高中 → 大学 → 大学；
  - 选「大学」（默认大儿子）：高中 → 大学 → 大学；
  - 选「小学」：小学 → 小学 → 初中。
  题目一旦在电视上展示过，就会自动标为「已用」，以后不再抽到（全家一起看，答案大家都记住了）。电视上不显示学段，只有你的手机能看到。

## 题库烧完怎么办
一局烧 12 道，大厅和主持人面板都会显示"题库可用 X 道"，快烧完时提前准备：
- **恢复已用题**：「题库」页顶部点「全部重新设为可用」，或者按「只看已用」筛选后逐题恢复。适合全家想重温一遍。
- **加新题**：下面三种方式，推荐第 1 种日常用、第 2 种批量用。

## 主持人面板
- **题库**：按分类、学段筛选，还可以按「可用/已用」筛选（玩过的题会自动标"已用"）；顶部的表格显示每个「分类×学段」有多少**可用**题，少于 6 题会标橙色；编辑题目时可以改它的学段，也可以手动把一道题标为已用/设为可用；搜索关键字；点 ＋ 新增，点「编辑」「删除」，保存立即生效。「待核对」是我自己没把握的题，建议你过一遍。
- **记分牌**：增删改选手（最多 6 位）、查看/删除单条记录、清空记录。
- **数据**：导出备份（题库+选手+记录一个 JSON 文件）、导入备份（可选"合并"或"覆盖"）、恢复默认题库，以及电视要打开的地址。

## 加新题的三种方式
1. **面板直接加**（日常零星加题）：「题库」页点右下角 ＋，填题干、四个选项、点圆点选答案、写两三句解析，保存立即生效。
2. **导入合并**（批量加题）：按照模板制作 JSON 文件 → 「数据」页 → 导入 → 选"合并"。按题干去重，已有的题不会重复，玩过标"已用"的题也不会被覆盖。
3. **改源码重新生成**（技术向）：题目源码在 `tools/build_questions.js` 里，加完题后在项目目录运行 `node tools/build_questions.js`，它会校验并重新生成 `defaults/questions.default.json`。注意：**这只更新默认题库，不会动你正在用的 `data/questions.json`**；想让新题进正在玩的库，走第 2 种方式导入。

## 数据和备份
全部数据在 `data` 文件夹：`questions.json`（题库）、`scores.json`（选手和记录）。直接拷走这个文件夹就是备份。
每次修改前，系统会在 `data/backups` 自动留一份带时间的备份（每个文件最多保留 40 份）。
对局进行到一半关掉电脑也没事，再启动会回到原来那一题。

## 可选：主持人口令
在 `config.json` 里把 `"hostPin": ""` 改成比如 `"hostPin": "1234"`，主持人面板就要输入口令，小孩就算知道地址也看不到答案。电视画面不受影响。重启后生效。

## 改奖金（config.json）
`config.json` 里只设一个 `"maxPrize"`（总奖金，默认 20），12 级奖金由程序按算法自动排好，改完**重启**生效：
```json
{
  "port": 3000,
  "hostPin": "",
  "maxPrize": 20
}
```

- 算法：按经典梯形的比例（各级约占总额的 2.5%→100%）缩放后取整，保证 12 级严格递增、最后一级正好等于总额。总额 50 会排成 `1→3→4→6→9→13→16→21→26→33→40→50`。
- `maxPrize` 必须是正数，写错了启动时会提示并用默认梯，不会坏。
- 高级用法：直接写 `"ladder": [12 个递增的数字]` 可完全自定义（优先级高于 `maxPrize`）；也支持环境变量 `MAX_PRIZE`。

## 兼容性
电视盒子的 Edge 是新内核，可以正常使用。电视上也可以用 scrcpy 镜像操作作为备用，不过推荐用手机浏览器当遥控器，更顺手。


## 从旧版升级（已经玩过、有记分和自己改过的题）
1. 关掉旧的游戏窗口，把新版文件解压到**另一个文件夹**；
2. 把旧版的 `data` 文件夹整个拷到新版文件夹里（覆盖空的 data）；
3. 照常双击 `start.bat`。第一次启动会自动：先备份旧题库 → 给旧题补上学段 → 新增 51 道新题（你删掉的旧题不会回来、你改过的题保持不变）；主持人面板顶部会出现「题库已升级」的提示。
4. 如果 data 里的文件损坏，新版不会再悄悄覆盖：会把坏文件改名保存（`*.corrupt-时间.json`），自动用最近的备份恢复，并在主持人面板顶部提示。
